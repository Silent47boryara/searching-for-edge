## Структура
- `scripts/` — пошаговые скрипты (`01…26`), запускаются по порядку; `bot_v2_extracted.py` — дословная копия функций BOS из `bot_v2.py` (хеш источника в заголовке).
- `raw/` — свечи BTCUSDT Binance (1d/4h/1h), загружены 2026-10-07, только закрытые.
- `out/` — промежуточные таблицы и графики Фазы 1, `out/phase2a/` — Фазы 2A.

## Чего здесь нет
- Исходных данных сборщиков (`oi_raw`, `funding_markprice_raw`, `liquidations_raw`, gamma, tape) — они велики и остаются локально; без них скрипты `05…26` не воспроизведутся, но готовые таблицы лежат в `out/`.
- Кода и логов бота `bot_v2`: в исходниках и логах бота обнаружены секреты, они не публикуются.
- Скрипты используют абсолютные пути `/Users/arefevoleg/…`, для запуска на другой машине их надо заменить.
