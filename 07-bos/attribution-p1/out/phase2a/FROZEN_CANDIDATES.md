## Кандидат 1 — агрессивный опционный поток перед стартом 1H-эпизода (из предрегистрированного семейства)

- **Событие:** старт 1H-эпизода BOS (`compute_impulse`, `tf=1h`, replay по закрытым свечам Binance); `T` — закрытие бара BOS; `s = +1` для BULL, `−1` для BEAR.
- **Признак:** `Fa_12h = s · (C_net − P_net) / Σ|N|`, где по всем BTC-опционным сделкам Deribit с `T−12ч < trade_time ≤ T`: `N = amount · index_price` (USD), знак — по `direction` тейкера (`buy` = +1, `sell` = −1), `C_net` — сумма знаковых `N` по колам, `P_net` — по путам. Блочные и комбо-сделки **включены**.
- **Валидность:** окно `[T−12ч, T]` вне исключения 2026-10-02 00:00 → 2026-10-06 23:05 UTC и вне периодов простоя сборщика tape; иначе `MISSING`.
- **Исход:** `MAE24` — максимальное неблагоприятное движение за 24 ч после `T` по low/high 1H-баров, направленно нормализованное (`≤ 0`; ближе к нулю — мягче).
- **Предсказанный знак:** `ρ_Спирмен(Fa_12h, MAE24) > 0`.
- **Наблюдалось в discovery:** n=14, ρ=+0,618, наивный p=0,020, Holm (10 тестов) 0,196, p_сдвиг=0,011, leave-one-out ρ ∈ [0,52; 0,73], знак положителен у BULL и BEAR и в обоих 1D-режимах. **Хрупкость:** без блочных/комбо сделок ρ=+0,35, только блочные/комбо ρ=+0,28; на переходах (n=37) ρ=+0,20.
- **Критерий форварда (предложение, утверждает владелец):** накопить не менее 14 новых валидных стартов 1H (при текущей частоте ~0,4 события/сут — около 5 недель), ρ>0 при одностороннем перестановочном p<0,05 по сдвиговому нулю; иначе кандидат закрывается как не воспроизведённый.

## Кандидат 2 — асимметрия unsigned gamma на мульти-ТФ переходах (post-hoc, вторичное семейство; не удовлетворяет правилу предрегистрации)

- **Событие:** переход мульти-ТФ вектора `(1D, 4H, 1H)` на сетке закрытий 1H (определение Фазы 1); `s` — направление активного 1D (если 1D неактивен — 4H, затем 1H).
- **Признак:** `Aa = s · (G_up − G_dn)/(G_up + G_dn)`, где по последнему снимку gamma Deribit с `ts ≤ T` (не старше 20 мин): `G_up = Σ gamma_exposure_per_1pct_move` по страйкам в `(spot, 1.05·spot]`, `G_dn` — по `[0.95·spot, spot)`; суммирование по кол/пут и всем экспирациям; **знак дилеров не выводится**.
- **Валидность:** снимок до 2026-10-02 10:10 UTC (после дыры — `MISSING`, пока непрерывный сегмент не достигнет достаточной длины).
- **Исход:** `MAE24`, как выше.
- **Предсказанный знак:** `ρ_Спирмен(Aa, MAE24) < 0`.
- **Наблюдалось в discovery:** n=36, ρ=−0,580, наивный p<0,001, p_сдвиг<0,001, прореженный (≥24 ч между событиями) n=20 ρ=−0,586, leave-one-out ρ ∈ [−0,68; −0,56], без точки A>0,6 ρ=−0,555, по периодам: до 16.09 ρ=−0,64 (n=22), после 16.09 ρ=−0,28 (n=14). **На стартах 1H (n=14) тот же признак даёт ρ=−0,20 (не значим).**
- **Статус отбора:** выбран ПОСЛЕ просмотра 262 вторичных тестов (наивных p<0,05 при n≥8: 20 из 204, ожидаемо по случайности ~10). Не имеет права называться кандидатом по правилу предрегистрации; заморожен по запросу владельца «зафиксировать эффект до новых данных».
- **Критерий форварда (предложение):** не менее 30 новых валидных переходов (около 4–5 недель; требует работающего gamma-сборщика), ρ<0 при одностороннем сдвиговом p<0,05.
