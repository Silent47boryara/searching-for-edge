# Фаза 2A — предрегистрация (зафиксировано ДО расчёта исходов и признаков)

Дата фиксации: 2026-10-07. Данные: всё, что есть на 2026-10-07 = DISCOVERY. Всё, что придёт после — forward/OOS.

## События (единицы)
- F1: старты 1H-эпизодов (17). F2: старты 4H-эпизодов (6). F3: мульти-ТФ переходы (43, из Фазы 1, заморожены).
- Для event study: конец 1H, конец 4H (ACTIVE→NONE), 1H-старт против активного 1D, потеря/восстановление полного выравнивания (все 3 ТФ ACTIVE в одну сторону).
- Момент решения T = закрытие бара BOS (эпизоды) / закрытие 1H-бара, где вектор изменился (переходы). Признаки только с timestamp ≤ T.
- Кластер = 1D-режим (эпизод 1D #1, пауза 1D NONE, эпизод 1D #2). Показывать всегда: N событий и N кластеров.

## Направление s
- Эпизоды: направление эпизода (+1 BULL, −1 BEAR).
- Переходы: направление активного 1D; если 1D неактивен — направление 4H, затем 1H.

## Исходы (P(T) = close бара, закрывшегося в T; издержки не моделируются)
R_h = s·(P(T+h)/P(T) − 1); MFE_h = макс. благоприятное, MAE_h = макс. неблагоприятное (≤0) по high/low 1H-баров в (T, T+h], с учётом s.
h ∈ {1,4,12,24,48,72} ч; если T+h за последним закрытым баром — наблюдение исключается из этого h (N показывается).
continuation: R_h>0; reversal: R_h<0; R_h=0 — ни то, ни другое, считается отдельно.
Контроль: безусловные R_h по всем часам окна для s=+1 и s=−1 (дрейф).

## Признаки (до T; свежесть OI 15м, funding 60с, gamma 20м; иначе MISSING)
- OI: ΔOI_w = OI(T)/OI(T−w) − 1, w ∈ {1,4,12,24} ч.
- Funding: f(T); Δf_w = f(T) − f(T−w), w ∈ {4,24} ч.
- Ликвидации (окно [T−w,T], w ∈ {1,4,12} ч; покрытие маски v2 ≥ 90%, иначе MISSING): L_long, L_short, total, imbalance I = (L_short − L_long)/total (total=0 → NaN, учитывается отдельно). Выровненный Ia = s·I.
- Gamma (только unsigned, pre-gap сегмент): G_up/G_dn = Σ gamma_exposure_per_1pct_move по страйкам в (spot, 1.05·spot] / [0.95·spot, spot); A = (G_up − G_dn)/(G_up + G_dn); Aa = s·A. Описательно: расстояние до страйка максимума (±15%) выше/ниже и его доля.
- Tape (окно [T−w,T], w ∈ {4,12} ч; вне исключения 2026-10-02 00:00→2026-10-06 23:05): нотионал = amount·index_price, знак по direction тейкера; flow = (call_net − put_net)/Σ|нотионал|; выровненный Fa = s·flow; IV = взвешенная по нотионалу средняя iv; block/combo — только счётчик.

## Первичное семейство (Holm по 10)
Выборка F1; признаки: ΔOI_24h, f(T) (s·f), Ia_12h, Aa, Fa_12h; исходы: R_24h и MAE_24h. 10 тестов.
Всё остальное (другие окна/горизонты/F2/F3) — вторичное, описательное, без права на «INTERESTING CANDIDATE».

## Статистика
Спирмен ρ(признак, исход), перестановочный p (10000 перестановок, наивный — не учитывает кластеры), знак ρ внутри каждого 1D-кластера при n≥4, контроль волатильностью: ρ(|доходность за 24ч до T|, исход). Доверительные интервалы по кластерам не строятся (кластеров 2–3).

## Статусы
- INSUFFICIENT DATA: n_valid < 8 или признаки есть менее чем в 2 кластерах.
- INTERESTING CANDIDATE (только первичное семейство): наивный p < 0.05 И одинаковый знак ρ в обоих 1D-режимах (n≥4 в каждом) И |ρ| > |ρ_vol| И n ≥ 10. Рядом всегда показывается Holm-скорректированный p и ожидаемое число ложных кандидатов при нулевой гипотезе (10×0.05 = 0.5).
- WEAK / INCONSISTENT: наивный p < 0.20 или |ρ| ≥ 0.20, но не выполнены условия кандидата.
- NO EFFECT: иначе.
VALIDATED не используется. Для кандидата точное определение (признак, окно, знак, исход) замораживается в отчёте.
